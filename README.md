## Dados tratados para divulgação acadêmica

A versão atual de [DataSET-03Jun2026.csv](DataSET-03Jun2026.csv) contém dados tratados: nomes, descrições livres, unidades, links SEI e identificadores originais foram removidos. Casos e documentos foram codificados e o calendário foi convertido em datas relativas a 01/01/2000, preservando intervalos e empates. Os 192 alinhamentos foram reproduzidos sem alteração dos resultados.

Para reproduzir o experimento, utilizar o [pacote completo de dados tratados e resultados](analises/pm4py_2026-11-25/dados_tratados/). A pasta contém entradas codificadas, modelos, código e resultados individuais. As datas sintéticas não representam o calendário administrativo original. A substituição do arquivo atual não elimina versões já registradas no histórico Git.
